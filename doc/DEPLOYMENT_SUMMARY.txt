🎯 DEPLOYMENT WORKFLOW
═══════════════════════════════════════════════════════════════════════════════

Development:
  Git Push → Jenkinsfile.build → Build & Test → Push Image 
    → Trigger Jenkinsfile → Deploy to Dev → Health Check → Done!

Staging:
  Manual Trigger → Select staging → Jenkinsfile 
    → Pull Image → Ansible Deploy → Health Check → Done!

Production:
  Manual Trigger → Approval Required → Select prod → Jenkinsfile
    → Pull Image → Ansible Deploy → Health Check → Done!

Rollback (Emergency):
  ansible-playbook -i ansible/inventory/prod \
    -e "rollback_to_version=v1.0.0" \
    ansible/playbooks/rollback.yml

🔧 KEY COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Test Ansible Setup:
  $ ansible all -i ansible/inventory/dev -m ping

Deploy to Dev:
  $ ansible-playbook -i ansible/inventory/dev \
      -e "app_version=1.0.0" \
      -e "docker_image=registry/stock-pos-server:latest" \
      ansible/playbooks/deploy.yml

Deploy via Jenkins:
  $ java -jar jenkins-cli.jar build stock-pos-server-deploy \
      -p ENVIRONMENT=dev -p RUN_TESTS=true

Health Check:
  $ curl http://localhost:3000/health

View Logs:
  $ docker logs -f stock-pos-app

Rollback:
  $ ansible-playbook -i ansible/inventory/prod \
      -e "rollback_to_version=v1.0.0" \
      ansible/playbooks/rollback.yml
